# kontur studio

Сайт студии с серверной формой заявок и защищённой админкой.

## Безопасность

Telegram username клиента сохраняется вместе с заявкой. Отправка заявок в Telegram отключена: для связи на сайте используется обычная ссылка на бота.

## Деплой через GitHub + Vercel

1. Создайте репозиторий на GitHub и загрузите содержимое этой папки.
2. Импортируйте репозиторий в Vercel.
3. В Vercel откройте **Project Settings → Environment Variables** и добавьте:
   - `ADMIN_PASSWORD` — длинный пароль для входа в `https://ваш-домен/admin.html`.
   - `SESSION_SECRET` — случайная строка минимум 32 байта для подписи HttpOnly-сессий.
   - `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` — серверные credentials проекта Supabase.
4. Выполните redeploy проекта.

GitHub Pages подходит только для статической части и не запускает `/api`. Для рабочей формы, cookie-сессий и админки нужен Vercel, Render, VPS или другой хостинг с backend.

## Админка и база

Откройте `/admin.html`. Авторизация выполняется сервером: пароль не сохраняется в браузере, а после входа выдаётся подписанная HttpOnly-сессия. Для операций администратора используется отдельный CSRF-токен.

Создайте в Supabase таблицу `leads`:

```sql
create table public.leads (
  id bigint generated by default as identity primary key,
  name text not null,
  telegram text not null,
  message text not null,
  created_at timestamptz not null default now()
);
```

GitHub Pages не запускает `/api`; для рабочей формы и админки подключите репозиторий к Vercel и добавьте переменные из `.env.example`. На одном GitHub можно хранить код, но нельзя безопасно запустить этот backend только средствами GitHub Pages.
